# spanning_tree

Status: **implemented** — CVK writes the managed leaves listed below on every reconcile.

- Shape: `singleton`
- netascode portal: [https://netascode.cisco.com/docs/data_models/iosxe/device/spanning_tree/](https://netascode.cisco.com/docs/data_models/iosxe/device/spanning_tree/)

## YANG paths

- `/Cisco-IOS-XE-native:native/spanning-tree`


## Managed leaves

The writer reads and writes the following leaves. Leaves outside this
set present on the device are preserved (additive merge).

- `mode`
- `extend`
- `portfast`
- `vlan`
- `mst`
