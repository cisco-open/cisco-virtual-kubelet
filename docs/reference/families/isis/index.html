    Status: implemented — CVK writes the managed leaves listed below on every reconcile.

    • Shape: keyed_list
    • Key field(s): tag
    • netascode inner key: processes
    • Depends on: interface_ethernet, interface_loopback
    • netascode portal: https://netascode.cisco.com/docs/data_models/iosxe/device/isis/
