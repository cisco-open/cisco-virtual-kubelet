    Build your workflow

    • Run applications

      Connect a device, make its application images accessible, and schedule a pod to its virtual node.

      Getting started · Image distribution

    • Declare configuration

      Express device intent with Network as Code and follow reconciliation, verification and drift.

      Network as Code · Migration guide

    • Use topology

      Understand protected device identity and labels, then place application Pods with native Kubernetes scheduling.

      Topology overview · Enable and enroll · Schedule workloads

    • Connect a controller

      Choose an Alpha adapter with the capabilities your workflow needs. SD-WAN apply is fixture-qualified; Nexus Dashboard covers health, inventory and opt-in device adoption.

      Catalyst SD-WAN · Nexus Dashboard

    Plan access and trust

    Use the security overview to choose the credential, TLS and authorization guidance for your role. Keep device administration separate from application-author permissions, and match your deployment to a published release. This documentation targets v2026.11.1; check publication status and upgrade older installations before using features introduced in November.

    For day-to-day diagnostics, telemetry and planned changes, continue to Operations. For field definitions and commands, use Reference.
