# Site credential acknowledged-task recovery

Public ordinary and credential-composed network-settings plans now compose a
site-assignment observation handler with their existing observers. This enables
acknowledged Unknown Update recovery through the same journal and writer.
Envelope/declaration checks reject taskless, duplicate, removed, inheritance,
foreign-shaped and malformed operations; the common loop still binds actual
owner/config/controller/source revisions. Native observation checks original
site and credential UUIDs, full task-tree success and stable declared effects
before and after observation. Persisted assignment verification repeats this
proof; no root-only task fallback is used.

Recovery never submits an assignment, changes a grant or creates a separate
ownership store. Existing global credential handlers remain composed. Legacy
isolated executor probes without task identities retain their limited readback
contract; they are not evidence of persisted task completion.

Native qualification uses the exact selected model bytes. Each assignment reaches
Unknown using the production timeout transition (a deliberately tiny 1ns test
timeout), preserves its original operation/task, completes verification and
reaches no-op after fresh reconciler instances. No journal phase is edited by the
harness. Private checkpoints retain all six original tasks and terminal idle
journals. Fixture setup creates isolated global definitions and one empty area;
supervised cleanup disables each generated-area slot, removes every generated
definition, and removes the empty area. Original credential identity/count
baselines are preserved. This cleanup is separate from manifest inheritance or
credential pruning.

Tests cover running/failed/unavailable task trees, no root fallback, native site
or credential replacement, late credential/slot drift, callback preservation and
malformed scope refusal. Old assignment fixtures returned only root tasks; they
were corrected to return correlated tree envelopes rather than weakening the new
observer. Native checkpoints contain only model references/status, not credential
values. Physical authentication and installed actor recovery are not qualified.
No taskless replay, source/owner transfer, inheritance removal, credential
pruning or full pinned-model parity is claimed.
