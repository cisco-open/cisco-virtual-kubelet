No device configuration, template attachment or successful policy activation was performed. The endpoint credentials and session material are excluded from this record.

    Expanded fixture run

    Additional live evidence:

    • All 24 classic policy-object collections: native create/read/update/read/delete.
    • Seven hierarchy nodes: three groups, three regions, one unassigned site; dependency-ordered creation, readback and reverse cleanup.
    • Eight additional feature-profile containers and their implicit application-priority settings parcel: native create/read, changed-value update/read, cleanup.
    • Full Go regression suite and focused race checks passed after these mappings.
    • Delayed accepted-create readback has a regression test preventing duplicate POSTs.

    The first policy fixture run found two Manager behaviors: long names are rewritten, while some type labels change capitalization. Short fixture names and explicit case normalization resolved these mismatches. Region lists require hierarchy regions; the fixture now supplies those prerequisites. An absent tertiary color preference was rejected by this Manager; the working fixture supplies all three preferences. The mapping includes the application-priority settings parcel that is created even when settings are omitted from YAML.

    The combined 44-resource Kubernetes/live reconciliation test passed in 730.69s, including idempotent convergence and receipt-based reverse cleanup. No device attachment, policy activation or router-level behavior is claimed. Untested upstream fields and resources remain visible in the coverage inventory instead of being counted as complete.

    System/CLI feature extension

    A separate native fixture set creates 12 objects: two isolated profiles plus ten feature parcels. Native lifecycle passed for CLI config, system basic, BFD, global, OMP, NTP, logging, MRF, flexible port speed and performance monitoring. The cycle cleaned up its created resources. Unsupported mapping expressions or validation keywords fail generation.     The separate 12-object Kubernetes/live reconciliation passed in 108.06s, including convergence and receipt-bound cleanup.

    SNMP, AAA and policy-profile definitions

    The singular policy-profile fixture and fifteen policy parcels passed compiler checks for all 16 objects. Native profile creation was rejected: this Manager already has its single permitted policy-object profile. No profile or parcel was created by that attempt. These sixteen declarations remain unqualified, pending a controlled existing-parent workflow or an empty Manager.

    NaC type references reviewed for numeric API encoding: TLOC preference and class-map queue. The latter documentation names class_maps; the pinned module instead consumes forwarding_classes. This discrepancy is recorded rather than silently renamed.

    AAA live Kubernetes reconciliation passed in 13.14s with idempotent convergence and receipt-bound cleanup.

    Full regression and focused race suites passed for this checkpoint. The final read-only sweep confirmed SNMP, AAA and isolated policy-profile fixture names absent.
